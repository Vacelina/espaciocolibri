# 🌿 Espacio Colibrí  

Bienvenido al repositorio de **Espacio Colibrí**, una página web creada como parte de un proyecto para un curso de Coderhouse. Este sitio está diseñado para el negocio de una amiga, lo que le da un enfoque real y práctico.  

## 🎯 Objetivo del Proyecto  
El principal objetivo es ofrecer una plataforma **atractiva y funcional** que represente la esencia del negocio, facilitando a los usuarios el acceso a la información y servicios que ofrece.  

## 👩‍💻 Sobre Mí  
Soy **Vanesa**, analista funcional y contadora de profesión, actualmente en proceso de migrar hacia el desarrollo de software y programación. Este proyecto representa un paso importante en mi transición, aplicando los conocimientos adquiridos en **Coderhouse**.  

## ✨ Características del Proyecto  
✅ **Diseño Responsivo**: Optimizado para distintos dispositivos, desde móviles hasta desktops.  
✅ **Interactividad**: Elementos interactivos para mejorar la experiencia del usuario.  
✅ **Contenido Informativo**: Información clara sobre los servicios del negocio.  
✅ **Uso de CSS y Sass**: Tecnologías modernas para mejorar el diseño y la estructura.  

## 🛠 Tecnologías Utilizadas  
- **HTML5**  
- **CSS3**  
- **Sass**
